# Videos locales

Sube aquí tus clips MP4 optimizados. Ejemplos de rutas para Google Sheets:
- `videos/cancion-001.mp4`
- `videos/cancion-002.mp4`

Usa nombres simples sin espacios ni acentos. En la columna `video` escribe la ruta relativa exacta desde la raíz del sitio. Recomendado: MP4 con H.264/AAC y tamaño reducido. GitHub Pages no es una plataforma de streaming; evita archivos grandes y revisa los límites de GitHub.
